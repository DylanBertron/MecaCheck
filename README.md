# MecaCheck V4

Prototype PWA orienté diagnostic automobile.

Sources intégrables:
- OBDex: DTC/PIDs open-data annoncé CC0/MIT
- NHTSA vPIC: décodage VIN public, avec limites et couverture spécifiques

Important: cette version n'intègre pas de données constructeur propriétaires, de SIV français, ni de schémas OEM.
